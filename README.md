# 8005-test-lab

Agent 优先的多机测试实验室。一个通用内核加上每个被测系统一个适配层，
第一个适配层是 WIRE_TO_GATE MVP。

**现在这个仓库里只有决策，没有代码。**方案正在用 wayfinder 一张票一张票地定下来，
图在 issue 列表里，标签 `wayfinder:map` 的那一条就是。它走完之后才有规格，规格
之后才有代码。

## 它要解决什么

被测系统分布在多台 Windows 机器上：一台服务端，若干台客户端，每台客户端旁边一个
仓位模拟器。客户端是 WPF 程序，操作员靠扫码和点按钮驱动它。今天能自动跑的只有
「三者全在一台机器上」的半实物层，多机、真车、跨机器的日志关联都还得人盯着。

lab 要让一个 coding agent 只靠一套 CLI 就能：起停任意机器上的任意角色、注入故障、
驱动界面、等待判据、回捞证据，然后读证据、改代码、重新部署、再跑一遍，直到通过。
